## Projeto em destaque

### Forecasting Platform

Plataforma de previsão de demanda desenvolvida em Python com arquitetura modular e foco em um fluxo de Machine Learning reproduzível, escalável e auditável.

O projeto contempla:

* ingestão e consolidação de diferentes fontes de dados;
* validação de schema e qualidade dos dados;
* preprocessamento;
* engenharia de features temporais e de negócio;
* seleção de features;
* divisão temporal dos dados;
* treinamento e comparação de modelos;
* avaliação de previsões;
* geração de forecast futuro;
* exportação de modelos e previsões;
* monitoramento e rastreabilidade das execuções;
* visualização dos resultados através de Streamlit.

Modelos trabalhados na plataforma:

`Baseline` • `Linear Regression` • `Random Forest` • `LightGBM` • `CatBoost` • `XGBoost` • `SARIMA` • `Prophet`
